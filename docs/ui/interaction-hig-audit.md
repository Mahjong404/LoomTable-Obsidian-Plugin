## Severity and disposition

- **P0 / MUST**: release-blocking HIG violation; fix in the next UI slice and add a focused regression or DOM/accessibility test.
- **P1 / SHOULD**: default behavior to adopt; if retained, document the reason in the owning component or View document.
- **N/A / scope**: capability is not present in the published main or is outside the approved P1.5 scope; do not invent it during this audit.
- “Test evidence” is intentionally marked pending until the corresponding fix is merged and its remote CI/main evidence is available.

## Approved repair order

1. **Status, error, focus and accessibility MUSTs**: translate existing UI copy, establish semantic Grid/Map/Detail state and focus seams, protect drafts, and add targeted DOM/accessibility tests.
2. **Theme and responsive consistency**: migrate semantic tokens, scope vendor CSS, remove fixed colors/global selectors, add reduced-motion and narrow-layout checks.
3. **Map-specific interaction**: keyboard-accessible markers/clusters, provider/tile error actions, and remaining attribution/provider configuration checks.
4. **Only after the above**: scheduler/error split, durable queue wiring, Grid/Detail/Map mutation wiring, and the approved Conflict UI flow.

Out of scope remains new Record creation/import, Relation/Formula/Lookup/Rollup, new View types, Dashboard, realtime collaboration, and undocumented automatic merge.
