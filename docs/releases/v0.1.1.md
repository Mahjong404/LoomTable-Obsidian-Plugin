# LoomTable Obsidian Plugin v0.1.1

## 发布基线

- Plugin main: `acfff36d082d556893ddc9eddc1379ffe6ed6421`
- Server OpenAPI source: `ef0c6bd751642f4a604fe1bf88980f64e39dd992`
- Plugin version: `0.1.1`
- Obsidian minimum version: `1.11.5`

这是在既有 `v0.1.0` 之后的补丁版本。旧 `v0.1.0` Release 仍指向 `5f5db46f37efb0f146cf53d7e8f6e3d36db179fb`，不包含本发布基线。

## 本次范围

- Connection Profile 的添加/删除按钮提供清晰的中英文文案和说明，不影响 Server 数据。
- Obsidian 语言选择支持跟随 Obsidian、English 和简体中文。
- Map Leaflet 已加载瓦片可见性修复；OSM 层不再向 Leaflet 传入 `subdomains: undefined`，显式天地图/自定义子域名保持不变。
- 保留 Grid 编辑、Mutation Queue、Conflict UI、Map Provider、凭据脱敏和既有 OpenAPI 生成类型。

## Live smoke 验收

- OSM：在真实 Obsidian Desktop/Electron 中通过认证 smoke；显示 `Tiles ready`，Fit all 后显示 2 条可渲染记录。
- 天地图：在 `app://obsidian.md` Origin 下使用浏览器端应用 Key，矢量与注记层返回 HTTP 200 PNG 并成功显示，界面显示 `Tiles ready` 与 Leaflet 天地图 Attribution。
- 天地图服务器端应用 Key：无 Origin 的服务端请求可返回 200 PNG，但在 Obsidian 桌面直连下返回 `301013`（权限类型错误）。因此 Plugin 直连必须使用浏览器端 Key，服务器端 Key 仅供服务端请求或代理。
- 标准 WMTS `tk` 请求不要求安全密钥才能使用；本仓库不包含任何真实 Key。

## 未纳入本次“已通过”范围

- 天地图影像、地形及其注记层的本次真实 smoke。
- 公共 Provider 的 SLA、长期配额和第三方账号策略。
