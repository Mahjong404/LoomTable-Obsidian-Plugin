- 每个源码包的**C-CODE**：指定focused Vitest → `pnpm typecheck` → `pnpm format:check` → `pnpm lint` → `pnpm test:run` → 合并前按workflow `pnpm check`（包含API生成/build，UI包要求生成diff/pin零变化）和`git diff --check`。实施时按最新package/CI要求，不把这份命令缓存当永久事实。
- **C-GALLERY**：`pnpm gallery`后打开实际 `tests/gallery/index.html`，生产factory、InMemory/typedfakes；实际入口`main.ts/scenarios.ts/data.ts/gallery.test.ts`。生成bundle不提交。每包覆盖相关Light/Dark、longtext/empty/disabled/error/320–400/600/960pane，正常desktop与coarse布局；不得复制独立demo组件。
- UI包如新增label/empty/error/tooltip均同步`src/i18n/messages.ts`、`zh-cn.ts`和相关aria断言。`tests/i18n/i18n.test.ts`只证键完整，不替代语义。
- 共同**DoD**：要求→node/doc→真实code→task→test/host可追踪；focused/required检查通过；有真实消费者与错误/边界用例；无无关diff、无secret/buildartifact/API意外变更；review完成、统一status有实际HEAD/PR/检查/host限制；未具备capability保持gated。
- **C-HOST**：按包说明做真实ObsidianDesktop关键路径、theme/窄Pane、keyboard/IME/focus/pointer/reducedmotion和cleanup；coarse/touch涉及项在可用实际Mobile验证，否则记录未验证，不能拿desktop模拟签Mobile通过。API/DB用专用合成环境，不改生产数据。CDP只是宿主测试工具，不创建第二旧Desktop Audit流程。
- 各包回滚以窄PR可revert、保留已验证前置接口为主；不通过重置数据库或删用户快照回滚。没有schema的LaneA包不应产生数据迁移。未知结果由原Queue/body/id处理，UI取消不撤回已发请求。
