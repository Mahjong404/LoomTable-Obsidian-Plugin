## 权威与范围

Figma 文件 [LoomTable](https://www.figma.com/design/91zxIAkX7C0MtLD4tJsE8H) 的三页入口为 [Foundations](https://www.figma.com/design/91zxIAkX7C0MtLD4tJsE8H?node-id=0-1)、[Primitives](https://www.figma.com/design/91zxIAkX7C0MtLD4tJsE8H?node-id=5-2)、[Product Components / Patterns](https://www.figma.com/design/91zxIAkX7C0MtLD4tJsE8H?node-id=5-3)。当前 [Picker Review](https://www.figma.com/design/91zxIAkX7C0MtLD4tJsE8H?node-id=326-102319) 消费权威组件实例。77 个 authority 入口包括 27 Primitive、47 Product/internal、3 Pattern；69 sets 的 678 个 variant master 加 8 个单独 glyph，数量是设计资产规模，不是代码类或任务数量。

Design System 负责视觉，HIG 负责交互，Grid Spec 负责 Grid 专属，Editor Lifecycle 负责技术所有权；任务卡负责应用与验收。Future/Deferred 是实施门槛，设计批准不自动解锁。各需求/节点下的源码与测试以真实模块重新定位，新增文件明确标为拟新增；不要沿旧行号假设源码未变。
